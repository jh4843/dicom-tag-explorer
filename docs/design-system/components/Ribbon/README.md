# Ribbon

메뉴바를 대신하는 리본으로, 파일·편집·보기·도움말 탭에 아이콘 명령을 그룹 단위로 배치한다.

- 탭 줄 `size-ribbon-tabs`(28px, `bg-100`), 본문 `size-ribbon-body`(84px, `bg-200`). 선택 탭은 `ink` `body-strong`에 `accent` 2px 밑줄, 나머지는 `ink-muted`.
- 탭 줄과 본문의 좌우는 창 가장자리 여백 `size-edge`(8px)다. 오른쪽 끝 접기 버튼도 이 여백 안에 둔다.
- 그룹은 `line` 세로선으로 나누고 그룹 이름은 아래에 `caption` `ink-muted`.
- 큰 버튼: 32px 아이콘 + `caption` 라벨(두 줄까지), 폭 58px. 작은 버튼: 16px 아이콘 + `body` 라벨, 높이 20px, 세 개씩 세로로 쌓는다. hover `bg-400`, 모서리 `radius-sm`.
- 폭이 모자라면 오른쪽 그룹부터 큰 버튼 → 작은 버튼 → 그룹 하나의 드롭다운(`shadow-popup`, `radius-md`) 순으로 줄인다.
- 오른쪽 끝 `ribbon-collapse` / `ribbon-expand`(Ctrl+F1)로 접고 편다. 접힌 상태는 저장한다.
- 탭별 명령:
  - 파일: 열기(파일 열기, 폴더 열기, DICOMDIR) · 파일(최근 파일 ▼, 닫기, 모두 닫기) · 앱(설정)
  - 편집: 복사(복사, TAG 복사, 행 복사) · 찾기(찾기, 상세 검색, 이전, 다음) · 이동(Offset으로 이동)
  - 보기: 탐색(탐색 Pane, 파일/WSI/DICOMDIR 분류) · 이미지(맞춤, 1:1, 확대, 축소, 좌회전, 우회전) · 레이아웃(영역 최대화, 레이아웃 초기화)
  - 도움말: 도움말(단축키 목록), 설정의 정보·라이선스로 가는 바로가기
- 명령은 하나의 `QAction` 레지스트리(이름, tr 텍스트, 아이콘 이름, 단축키)에서 가져온다. 리본은 소비만 한다.
