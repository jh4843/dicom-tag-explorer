# DIR v0.1.0 — 요구사항 (Design Input Requirements)

- 버전: v0.1.0
- 작성일: 2026-10-26
- 작성: leader
- 상태: 확정(G1) <!-- 초안 / 검토중 / 확정(G1) -->

## 1. 목표

WSI DICOM 파일 여러 개를 열어 파일·WSI 이미지·DICOMDIR 기준으로 분류해 탐색하고, 선택한 대상의 Tag Tree, RAW(Hex) 값, 이미지를 한 화면에서 확인·검색할 수 있는 Windows 데스크톱 도구를 만든다.

## 2. 범위

- 포함: 다중 파일 열기, 좌측 분류 트리(Docking/Floating), Tag Tree, RAW Hex 뷰, 이미지 뷰(Pan/Zoom/Rotate), WSI 피라미드 통합 뷰, 통합·상세 검색, 설정 창(언어·테마·라이선스·정보), 영어/한국어 UI, 다크(기본)/라이트 테마, 커스텀 타이틀바, 리본 UI
- 제외: Tag 편집·저장, 익명화, DICOM 네트워크(C-FIND/C-MOVE, DICOMweb), 주석(Annotation) 표시, WSI 개요 미니맵

## 3. 요구사항

분류는 `기능`, `비기능`, `DICOM 적합성`, `라이선스` 중 하나. 우선순위는 `Must`, `Should`, `Could`.

| Q-03 | 상세 검색 옵션 범위 (대소문자 구분, 정규식, 여러 컬럼 AND 조건) | 사용자 | 여러 컬럼 AND + 대소문자 구분·정규식 옵션 |
